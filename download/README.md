# Mahmudul Hasan — Portfolio Website

A premium, production-ready personal portfolio built with Next.js 16, TypeScript, Tailwind CSS 4, and Framer Motion.

## Live Preview

- Preview link: `https://preview-<bot-id>.space-z.ai/`
- Local dev: `http://localhost:3000` (sandbox only)

## What's inside

### Sections (11 total)
1. **Hero** — cinematic name reveal, animated grid, cursor-reactive glow, floating keywords, magnetic CTAs
2. **About** — engineering identity narrative + 3 info cards (Education, Focus Areas, Current Goal)
3. **Featured Achievement** — Champion UIU CSE Project Show Fall 2025 with #01 treatment and team credits
4. **Projects** — 6 projects with category filters, 3D tilt cards, hover-following glow, full detail modal
5. **Skills** — grouped marquee + 6 categorized cards (no fake proficiency bars)
6. **Journey** — engineering timeline with animated vertical line and alternating cards
7. **Research** — RCDR animated pipeline diagram (Sense → Detect → Intervene → Observe → Update)
8. **Currently Building** — live status indicators for active work
9. **GitHub Activity** — public repos only (CareerOS marked Private), no fabricated metrics
10. **Resume** — CV download + LinkedIn + at-a-glance summary
11. **Contact** — strong closing CTA with Email / LinkedIn / GitHub

### Premium features
- Custom cursor with state-aware labels (default / button / project / link)
- Magnetic buttons with spring physics
- Scroll progress bar
- Page intro animation (monogram → line → fade)
- Sticky glass navigation with active section tracking
- Mobile slide-in menu with staggered entrance
- Easter egg terminal (Ctrl + ` or floating button) — try `help`, `whoami`, `projects`, `skills`, `contact`, `cv`
- Animated project visuals (SVG-based, no stock images) — distinct identity per project
- Reduced-motion support throughout
- Full SEO: title, meta description, OpenGraph, Twitter cards, sitemap, robots, manifest

## ⚠️ Replace the CV

The file at `public/Mahmudul-Hasan-CV.pdf` is a **placeholder PDF** generated by `scripts/make_cv_placeholder.py`. Replace it with the real CV — the UI references this path via `siteConfig.cvPath` and triggers a direct download via the `download` attribute on every CV button.
